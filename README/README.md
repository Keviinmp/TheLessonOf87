# [TheLessonOf87]

Fan game educativo hecho en Unity como proyecto de fin de grado (CFGS Desarrollo de Aplicaciones Multiplataforma). Sin ánimo de lucro.

Recorres el mapa de la primera entrega de FNAF en primera persona e interactúas con objetos del entorno para responder preguntas de inglés. Si fallas 3 veces, salta un jumpscare con el personaje de esa prueba.

## Qué incluye el código

- Sistema de pruebas con 4 bancos de preguntas en JSON (gramática, vocabulario, traducción, sinónimos y antónimos), 300 preguntas cada uno, generadas con IA.
- Gestión de vidas, registro de errores y tiempo de partida.
- Interacción en primera persona con objetos del entorno.
- Jumpscares por vídeo, sonidos y easter eggs.

## Tecnologías
Unity, C#

## Aviso
Este repositorio contiene solo los scripts. Los modelos 3D, sonidos y vídeos no se incluyen porque no tengo derecho a redistribuirlos, por lo que el proyecto no se puede ejecutar tal cual. FNAF y sus personajes son propiedad de su creador.
